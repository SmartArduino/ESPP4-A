# ESPP4-A 模组介绍

## 概述

ESPP4-A = 乐鑫 ESP32-P4 主控 + 无线芯片（WiFi + BLE），两者在模组内通过 SDIO 连接。

ESP32-P4 是乐鑫面向多媒体 / HMI 的高性能芯片，芯片本身**没有 WiFi 和蓝牙**。本模组集成无线芯片，并提供 [p4_wireless](../components/p4_wireless/) 组件，应用层直接用 ESP-IDF 标准的
`esp_wifi`、`esp_netif`、NimBLE 接口，不需要关心底层驱动。

## 主要规格

| 项目 | 说明 |
| --- | --- |
| 主控 | ESP32-P4，双核 RISC-V（另有一个低功耗 LP 核） |
| 片内 RAM | 768 KB HP L2MEM |
| Flash | 16 MB（例程按 16 MB 配置） |
| PSRAM | 支持，例程按 Hex 模式 250 MHz 配置 |
| WiFi | 2.4 GHz / 5 GHz，STA / SoftAP（不支持两者同时运行） |
| 蓝牙 | BLE，host 使用 ESP-IDF 自带的 NimBLE（不支持 Bluedroid） |
| 天线 | 模组 `RF_WF` 引脚输出射频，需外接天线（DevKit 板载天线） |
| 封装 | 72 个引脚 |

ESP32-P4 主要多媒体外设：MIPI-DSI（2-lane）、MIPI-CSI（2-lane）、ISP、PPA（旋转/缩放/混合）、
2D-DMA、JPEG 编解码、H.264 编码、USB 2.0 高速 OTG、以太网 MAC、SDMMC 等。完整参数请看乐鑫
《ESP32-P4 技术规格书》。

## 方案优势

ESP32-P4 常见的联网方案是外挂一颗 ESP32-C5 / C6，通过乐鑫 [ESP-Hosted](https://github.com/espressif/esp-hosted-mcu) 提供 WiFi / BLE。与之相比，ESPP4-A 有以下优势。

### 集成度

- **单模组**：P4 与无线芯片在模组内部通过 SDIO 连接，PCB 上不需要第二颗芯片或模组，也不需要布 SDIO、复位、唤醒等互连走线。
- **一份固件**：无线固件存放在 P4 的 Flash 中，`esp_wifi_init()` 时由驱动加载。无线芯片不需要单独烧录，OTA 时随应用一起更新，不存在主从固件版本不匹配的问题。
- **接口不变**：应用使用 ESP-IDF 标准的 `esp_wifi`、`esp_netif` 和 NimBLE 接口，与 ESP-Hosted 方案的应用代码写法一致。

### WiFi 吞吐

均为 5 GHz 频段、SDIO 4 线 40 MHz，单位 Mbit/s：

| 方向 | ESPP4-A | ESP32-P4 + ESP32-C5 |
| --- | ---: | ---: |
| TCP 上行（板子 → PC） | **42.7** | 23 |
| TCP 下行（PC → 板子） | **40.1** | 32 |
| UDP 上行（板子 → PC） | **76.0** | 67 |
| UDP 下行（PC → 板子） | **85.4** | 68 |

- ESPP4-A：`wifi_cmd` 例程 + iperf 2，PC 有线连接路由器实测。
- ESP32-P4 + ESP32-C5：取自乐鑫 ESP-Hosted 官方公布的数据（[performance.md](https://github.com/espressif/esp-hosted-mcu/blob/main/docs/design/performance.md)），开放环境、未使用屏蔽箱。

两组数据的路由器和信道环境不同，适合比较量级；实际吞吐受路由器和信道环境影响较大，2.4 GHz 下明显更低。

## 模组内部占用的引脚

| GPIO | 用途 |
| --- | --- |
| GPIO14 ~ GPIO19 | 无线芯片 SDIO（CLK=18，CMD=19，D0~D3=14~17），未引出 |
| GPIO54 | 无线芯片复位，被 `p4_wireless` 占用，**不要另作他用** |

无线芯片使用 SDMMC **Slot 1**，TF 卡请使用 **Slot 0**（GPIO39~44），两者不冲突。

## 使用注意

- **Strapping 引脚**：GPIO34 ~ GPIO38 上电时的电平会影响启动模式。GPIO35 是 BOOT 键；
  GPIO37/38 是默认调试串口 UART0。外接电路时不要在上电瞬间强拉这些引脚。
- **供电**：WiFi 与 BLE 同时工作时电流峰值较大，3.3 V 供电不足会出现
  `E BOD: Brownout detector was triggered` 并复位。
- **授权**：`p4_wireless` 与模组绑定，在非配套模组上 `esp_wifi_init()` 返回 `ESP_FAIL`。
  授权使用 eFuse `BLOCK_KEY5`，请勿在该块上烧写其它密钥。
