# 常见问题

## WiFi / BLE

| 现象 | 原因与处理 |
| --- | --- |
| `esp_wifi_init()` 返回 `ESP_FAIL` | 模组不是配套模组（授权不通过），请联系供应商确认 |
| 连上 AP 但拿不到 IP，日志提示 `wifi netif not found` | 没有在 `esp_wifi_init()` 之前调用 `esp_netif_create_default_wifi_sta()` |
| 日志 `p4w_hci: HCI open failed` | NimBLE 在 `esp_wifi_init()` 之前初始化了，调换顺序 |
| 编译报 `This SOC does not support BLUFI` | 见 [blufi 例程](../components/p4_wireless/examples/blufi/README.md) |
| 运行中复位，日志 `E BOD: Brownout detector was triggered` | 3.3 V 供电不足，检查电源和线材 |

## 显示 / 摄像头

| 现象 | 原因与处理 |
| --- | --- |
| 屏幕不亮 | 确认排线插好；背光使能是 GPIO24，高电平点亮 |
| 画面整体偏移 | 使用板级定义里的屏幕时序，不要改动 |
| 换了 `esp_lvgl_port` 版本后编译通过但运行异常 | IDF 5.5 下 `esp_lvgl_port` 要用 ~2.6（2.9 需要 IDF 6）；改版本后执行 `idf.py fullclean` |
| `esp_cam_sensor` 找不到 GC4023 | 官方组件不支持该传感器，把 [components/gc4023](../components/gc4023/) 加入 `EXTRA_COMPONENT_DIRS` |

## 烧录

| 现象 | 原因与处理 |
| --- | --- |
| `Failed to connect to ESP32-P4` | 按住 BOOT，按一下 RST，松开 BOOT 后重新烧录 |
| 找不到串口 | 确认插的是 UART-DEBUG 口，并已安装 CH340 驱动 |
