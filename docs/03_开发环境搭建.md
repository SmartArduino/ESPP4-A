# 开发环境搭建

ESPP4-A 使用乐鑫官方的 **ESP-IDF** 开发，要求 **v5.5 及以上**（推荐 v5.5.3）。
下面以 Linux / WSL 为例；Windows 可直接用乐鑫的 ESP-IDF 离线安装包，之后的 `idf.py` 命令完全一样。

## 1. 安装 ESP-IDF

```sh
# Ubuntu 依赖
sudo apt-get install git wget flex bison gperf python3 python3-pip python3-venv \
    cmake ninja-build ccache libffi-dev libssl-dev dfu-util libusb-1.0-0

# 下载 ESP-IDF v5.5.3
mkdir -p ~/esp && cd ~/esp
git clone -b v5.5.3 --recursive https://github.com/espressif/esp-idf.git

# 安装 ESP32-P4 工具链
cd esp-idf
./install.sh esp32p4
```

国内网络慢时可以用乐鑫的 Gitee 镜像和 `IDF_GITHUB_ASSETS="dl.espressif.cn/github_assets"`，
详见乐鑫文档「ESP-IDF 快速入门」。

每次打开新终端都要先导入环境：

```sh
source ~/esp/esp-idf/export.sh
```

## 2. 连接开发板

用 Type-C 线连接开发板的 **UART-DEBUG** 口（CH340X 串口）。

- Linux：一般是 `/dev/ttyUSB0`，没权限时执行 `sudo usermod -aG dialout $USER` 后重新登录。
- Windows：设备管理器里看到的 `COMx`，需要先安装 CH340 驱动。
- WSL：串口需要用 `usbipd` 转进 WSL，或者在 Windows 侧烧录。

## 3. 编译、烧录、看日志

以 `wifi_cmd` 为例：

```sh
cd components/p4_wireless/examples/wifi_cmd
idf.py set-target esp32p4        # 只在第一次执行（会清空当前 sdkconfig）
idf.py menuconfig                # 按需修改配置，可跳过
idf.py build
idf.py -p /dev/ttyUSB0 flash monitor
```

`monitor` 中按 `Ctrl+]` 退出。

如果自动进入下载模式失败（提示 `Failed to connect`），手动操作：按住 **BOOT** 键，按一下 **RST**，
松开 BOOT，再重新执行烧录命令。

## 4. 例程工程说明

- `sdkconfig.defaults`：例程需要的配置（Flash 16 MB、PSRAM 等），`set-target` 时自动生效。
  本机 `sdkconfig` 是生成文件，要长期保留的配置请写进 `sdkconfig.defaults`。
- `main/idf_component.yml`：依赖的在线组件（如 LVGL），首次编译自动下载到 `managed_components/`。
- 修改 `idf_component.yml` 里的组件版本后，建议执行 `idf.py fullclean` 再编译，
  避免旧的编译产物与新组件不匹配。

## 5. 在自己的工程里使用 WiFi / BLE

1. 把 [components/p4_wireless](../components/p4_wireless/) 整个拷到你工程的 `components/` 下。
2. 按组件 README 设置 `sdkconfig.defaults` 和分区表，可直接参考 `components/p4_wireless/examples/wifi_cmd`。
3. 和 ESP32 一样调用 `esp_wifi` API。

详细步骤见 [p4_wireless/README.md](../components/p4_wireless/README.md)。
